SPN 624 — Yellow Warning Lamp

Updated: 2026-11-14

Safe to driveDrivable, but watch it yourself

J1939 code SPN 624. Below — how the fault is worded at the factory by International, KAMAZ, MAZ and YaMZ, and what the second half of the code (FMI) means in the standard.

How to check it yourself

The yellow warning lamp — the fault warning light. The code is about the lamp's own circuit: the unit cannot switch it on. On new vehicles the lamp is on the dash and the command comes over CAN.

Check order

  1. When the ignition is switched on, does the lamp light for the check?
  2. Lamp on a wire: the dash connector, the wire, the lamp itself.
  3. Over CAN — the unit's link to the dash (SPN 639).
  4. While the lamp does not work, the driver will not know about other faults — read the codes with diagnostics.

Common causes — from most to least frequent

  1. Link to the dash.
  2. Lamp wire or connector.
  3. The dash itself.
